# Imágenes para Asadero La Bonita

## Imágenes requeridas para el menú:

### Combos de Pollo Asado:
- `pollo completo.webp` - Imagen de un pollo entero asado al carbón
- `medio pollo.webp` - Imagen de medio pollo asado
- `cuarto pollo.webp` - Imagen de un cuarto de pollo asado

### Acompañamientos:
- `papas fritas.webp` - Imagen de papas fritas doradas y crujientes
- `yuca frita.webp` - Imagen de yuca frita dorada
- `arepa.webp` - Imagen de arepa asada al carbón
- `ensalada verde.webp` - Imagen de ensalada fresca con tomate y cebolla

## Especificaciones técnicas:
- Formato: WebP (recomendado) o JPG
- Tamaño: 300x300 píxeles mínimo
- Calidad: Alta resolución para web
- Estilo: Imágenes apetitosas y profesionales
- Fondo: Preferiblemente fondo neutro o transparente

## Consejos para las imágenes:
1. **Pollo asado**: Mostrar el pollo dorado y jugoso, con especias visibles
2. **Acompañamientos**: Mostrar los alimentos frescos y apetitosos
3. **Iluminación**: Buena iluminación que resalte los colores naturales
4. **Composición**: Enfoque en el producto principal, sin distracciones

## Ubicación de archivos:
Coloca todas las imágenes en esta carpeta (`img/`) con los nombres exactos especificados arriba.
